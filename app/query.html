Use the same tables from Python, R or the DuckDB CLI

# The Parquet files are public static assets: query them over HTTP.
import duckdb
duckdb.sql("INSTALL httpfs; LOAD httpfs;")
duckdb.sql("""
  SELECT name, prov, mpi
  FROM 'https://darbar.adaad.org/data/warehouse/mpi_districts.parquet'
  WHERE low_n = 0 ORDER BY mpi DESC LIMIT 10
""").show()

# R
arrow::read_parquet("https://darbar.adaad.org/data/warehouse/mpi_districts.parquet")

      
How this works
        
There is no server. The tables are Parquet files beside this page and DuckDB-WASM runs inside your browser: small tables load when the page opens, large ones only when a query names them, and only the parts it reads where the host allows. Full DuckDB SQL works: CTEs, window functions, PIVOT, corr(). The link carries your SQL, so a query can be shared. Downloads can carry method notes: a README with each table's source, unit, caveats and fields.
