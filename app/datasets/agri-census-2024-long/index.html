Read before using

One row per figure in PBS’s 357 published Excel tables (Chapters 1–8: farms and tenure, fragmentation, land use, irrigation, intensities, crops, livestock, machinery). Block tables carry the farm-size, herd-size or tenure class in category and any nested sub-heading in group; flat tables (7.1 livestock, 8.x machinery) have one row per unit and no category. column is PBS’s own header, levels joined with a bar, spellings kept (TANENT, HOPUSEHOLD). The same caveats as agri_census_2024_district: weighted sample estimates, 15 per cent design margin at district level, zero rows omitted, a few districts with implausible farm counts. The national file repeats the provincial totals, so sum within one source_file. table_id is text (T6.10 is not T6.1).
