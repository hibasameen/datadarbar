Read before using

parsed_into_db = FALSE means the file is catalogued but its contents are not in any table here (mostly scanned PDFs). Use this to check coverage before concluding data is missing.

Use it in code

-- DuckDB, in the browser console or the CLI
SELECT * FROM 'https://darbar.adaad.org/data/warehouse/file_catalog.parquet' LIMIT 10;

# Python
import duckdb
duckdb.sql("INSTALL httpfs; LOAD httpfs;")
df = duckdb.sql("SELECT * FROM 'https://darbar.adaad.org/data/warehouse/file_catalog.parquet'").df()

# R
