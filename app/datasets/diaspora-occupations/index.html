Read before using

Forty occupation categories for one year. Labourer is the largest at 364,574, about half of all emigration that year.

3 columns, in file order.

Use it in code

-- DuckDB, in the browser console or the CLI
SELECT * FROM 'https://darbar.adaad.org/data/warehouse/diaspora_occupations.parquet' LIMIT 10;

# Python
import duckdb
duckdb.sql("INSTALL httpfs; LOAD httpfs;")
df = duckdb.sql("SELECT * FROM 'https://darbar.adaad.org/data/warehouse/diaspora_occupations.parquet'").df()
