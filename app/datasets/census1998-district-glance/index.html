Read before using

PBS’s District at a Glance (1998), one sheet per district, long format: about twenty indicators each. These sheets are on the districts as they stood after the 2000-01 changes - Umerkot apart from Mirpur Khas, City District Karachi as one - so they do not match census_admin_units_1951_1998, which keeps the 1998 frame (Mirpur Khas there includes Umerkot’s 663,095). Charsadda’s sheet is linked by PBS but the file is refused by its server, so Charsadda is absent; its population is in the admin units table. District names are as PBS titled them, misspellings included (SHAIWAL, JACCOBABAD). share_pct is the percentage PBS prints beside a figure. A figure that cannot be what its label says is not read: Ghotki’s household size is printed 505, so value is NULL and flag says why.

Use it in code

-- DuckDB, in the browser console or the CLI
SELECT * FROM 'https://darbar.adaad.org/data/warehouse/census1998_district_glance.parquet' LIMIT 10;
