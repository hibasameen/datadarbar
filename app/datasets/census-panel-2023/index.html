Read before using

Do not sum across unit_type, locality or sex — each is a nested hierarchy and adding the levels together double- or triple-counts. Tables are not uniform about the sex column: in tables 1, 3, 21 and 25, 15,141 rows carry the sex split in the indicator label while sex stays 'all', so filter on the indicator there rather than on sex. Table 1 also republishes a POPULATION 2017 column beside the 2023 figure — that is PBS's own comparison and is safe to use, unlike joining this panel to census_panel_2017. is_rate = TRUE marks the 624,219 rows that are rates or percentages and must never be summed. missing = TRUE on 1,565,334 rows marks a cell PBS printed as a dash, and unlike the 2017 panel the value is left NULL rather than recovered as zero, so a count of non-missing cells is not comparable between the two years. renderings_disagree = TRUE on 27,033 rows flags a figure where PBS's two published renderings of the same table do not agree. adm3_pcode and dd_id are the geographic join keys and are incomplete by design: both are NULL on every district row, and dd_id — the key the site's own tehsil geometry uses — is present on 1,919,489 of 2,069,879 tehsil rows. Comparing to census_panel_2017 by table_id or indicator is unsafe: the numbering differs and only 50 indicator labels match verbatim. PBS's own spelling is kept, including 'EDUCATOINAL ATTAINMENT'.

province_areavarcharprovince, or FATA / Islamabad Capital Territory — the census frame has four provinces and two federal areas, not six provinces
table_idvarcharPBS table number WITHIN that census. Numbering is not comparable across years: 2017's table 23 is a locality table, 2023's is drinking water

dd_id keyvarcharidentifier used by the site's tehsil geometry; NULL on district rows
adm3_pcode keyvarcharCOD-AB ADM3 code; NULL on district rows and on units without a match
district keyvarchardistrict the unit sits in; equal to unit on district rows
unitvarcharthe published unit's own name
unit_typevarchardistrict, tehsil, sub_tehsil, sub_division or other. Rows of DIFFERENT unit_type are nested, so summing across them double-counts
map_key keyvarcharthe PBS Digital Census 2023 shape this row is drawn on — the district code on district rows, dds_id below that. NULL where no 2023 shape can carry the figure, which for 2017 means the unit was split or redrawn
map_relationvarcharhow this unit relates to the 2023 frame: exact, renamed, merged, split, boundary transfer, or restructured below the district
map_comparablevarcharyes where the figure belongs on the 2023 shape as published; combined where two 2017 units share one 2023 shape and must be added, or averaged on map_weight for a rate; flagged where the district persists but its territory changed; no where nothing can honestly be drawn
map_notevarcharthe reason, in words, for anything other than a straight match — written to be shown to a reader, not parsed
map_weightdouble2017 population, the weight for averaging a rate across units that combine into one 2023 shape
localityvarcharall, rural or urban. rural + urban = all, so pick one
sexvarcharall, male, female or transgender. The three sexes sum to all, so pick one
indicatorvarcharthe indicator as PBS labels it, joined with / down the header hierarchy
col_labelvarcharthe column heading the value sat under, kept because the same indicator can appear under several columns
valuedoublethe published figure — unit depends on the indicator, see notes
missingbooleanthe cell was printed as a dash rather than a number
is_ratebooleanthe value is a rate or percentage and must not be summed
value_correctedbooleanthe figure was corrected against the other rendering
renderings_disagreebooleanPBS's two renderings of this table disagree here
unit_sourcevarcharthe district workbook this row was read from
