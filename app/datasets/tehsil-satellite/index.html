Read before using

RWI is Meta's Relative Wealth Index — note it USES night-time lights as one of its own inputs, so rwi and the light columns are NOT independent measurements; a correlation between them is partly mechanical. Lights are June VIIRS radiance, population-weighted. The full year-by-year series is in tehsil_nightlights.
